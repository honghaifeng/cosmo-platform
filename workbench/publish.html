先出发布包，别急着接 API

阶段一不自动直发：生成发布包（标题 / 正文 / 话题 / 图片路径 / 自查清单），人工粘贴到平台。 这不是能力不足，是刻意的——批量直发会触发风控，而且发出去的内容一旦有问题，撤回的成本远高于人工发的麻烦。

为什么不直发

风控。批量自动发布会触发平台保护，账号一被打标，后面连正常采集都受影响。
留痕。人工发的每条都有时间、账号、链接，出了问题能说清是谁在什么时候发的什么。
闭环还没建好。自动发布要配上「发布后自动回采 + 数据回流」，否则发出去就断了。这个闭环建好再谈直发。
