二、小红书核心发现

  • MitoQ 是唯一「品类教育 + 品牌心智」双成功的品牌：高赞笔记是真实功效向 UGC（「瘦子也可能有脂肪肝」4,353 赞、「吃姜黄素的后果」2,049 赞），普通用户自发产出，评论区有服用多年的老用户理性讨论。
  • LAIFE 内容工业化程度最高：20 篇笔记里高频出现「花巢保养」「卵巢护理」等自造概念词，模板化种草痕迹明显（标题带 emoji 的统一句式），但互动效率确实高（1,694 条评论）。
  • 塞乐瑞的高互动是「虚假繁荣」：其收藏（13,674）和评论（4,713）数据亮眼，但拆开看——总赞第一的单篇（7,864 赞）是「本公主才是格兰岛的未来之星」这类娱乐蹭词内容，与产品无关；真实产品笔记（「Selay 赖氨酸停服两周」156 赞）互动远低于竞品头部。
  • W+端粒塔在小红书同样靠娱乐蹭词：Top 笔记是「AI 建模脸」「蔡依林不会老」等抗衰猎奇向内容，产品向笔记最高仅 299 赞。「端粒」概念在小红书没有形成有效心智渗透。
  • GRANVER 小红书存在感最弱：有模板化护肝种草（「Granver吉利肝」话题矩阵），但互动数据（2,152 赞）在五品牌垫底，其主战场明显在抖音直播/达人侧。

三、抖音核心发现

  • LAIFE 在抖音一骑绝尘（94,107 赞）：与其小红书策略一致，靠剧情化/科普混剪 + 直播切片矩阵，评论区互动（3,512）也最活跃，但同样混有「你也没说是不是智商税呀」「吃了 7 瓶也没用」这类质疑。
  • GRANVER 抖音互动 27,336 赞但评论区以主播互动客套为主（「主播好」「老师讲得好」），真实用户反馈密度低，互动质量存疑。
  • MitoQ 抖音内容以品类科普为主，品牌绑定「姜黄素/线粒体」关键词的策略与小红书一致。
  • 塞乐瑞和 W+端粒塔在抖音基本没有运营阵地（合计互动不足 5,000），与其「百度 PR + 小红书蹭词」的打法吻合——它们的重心根本不在短视频平台。

四、口碑与质疑（922 条评论实采）

评论关键词命中：「效果」类讨论 51 条、「有效」20 条、「推荐」8 条；负面信号：「智商税」4 条、「没用」4 条。样本量尚小，以下是代表性原声：

「智商税」质疑集中在高端定价品牌：
W+端粒塔（抖音）：「割韭菜的东西智商税交的太贵了」
塞乐瑞（小红书）：「这个有效果吗？是不是智商税？」
LAIFE（抖音）：「主要是含量有多少？2.0 吃了 7 瓶也没用」
MitoQ 的负面更「资深」：
MitoQ（小红书）：「吃了五六年了，几乎没停过……也没觉得它是仙丹妙药」——长期用户的理性祛魅，不是攻击而是祛魅
对自有品牌的启示：负面不是「效果差」而是「说不清值不值」。LAIFE/塞乐瑞/端粒塔的评论区普遍缺少品牌方对「为什么值这个价」的回应，这是可进攻的空位。
